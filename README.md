# Sagar Sagat - Portfolio Website

A clean, modern, and responsive personal portfolio website built with HTML5, CSS3, and vanilla JavaScript.

## 🚀 Features

- **Responsive Design**: Flawlessly adapts to desktop, tablet, and mobile screens.
- **Dark & Light Mode**: Built-in theme switcher with automatic preference persistence via `localStorage`.
- **Dynamic Hero Section**: Interactive typing animation and code snippet preview card.
- **Project Showcase & Filter**: Filter projects by categories (All, Frontend, Full Stack).
- **Skills & Tech Stack**: Organized breakdown of frontend, backend, database, and dev tools.
- **Experience Timeline**: Structured milestones displaying professional and technical progression.
- **Interactive Contact Form**: Client-side validated form with loading states and animated feedback alerts.
- **Accessible & Clean Code**: Semantic HTML5 markup, zero external framework dependencies, and pure vanilla JS.

## 📂 Project Structure

```text
├── index.html       # Semantic HTML5 markup and portfolio layout
├── style.css        # Custom CSS with design tokens, themes, and animations
├── script.js        # Dynamic theme toggling, menu navigation, filtering, and form handling
└── README.md        # Project documentation
```

## 💻 Getting Started

You can open and view this portfolio locally without any external build steps:

1. Clone or download the repository.
2. Double-click `index.html` to open it in your favorite browser, or serve it using any local static file server (e.g. VS Code Live Server or `python3 -m http.server`).
